# 📁 Python File Organizer

A Python automation tool that automatically organizes files into separate folders based on their file types.

## 🚀 Features

- Automatically detects file extensions
- Creates category folders
- Organizes Python files
- Organizes text files
- Organizes images
- Organizes documents
- Moves files automatically
- Reduces manual file management

## 📂 Supported File Types

| Category | Extensions |
|---|---|
| Python | `.py` |
| Text | `.txt` |
| Images | `.jpg`, `.jpeg`, `.png` |
| Documents | `.pdf`, `.docx` |

## 🛠️ Technologies

- Python
- OS module
- File handling
- Loops
- Dictionaries
- Automation

## ▶️ How to Run

1. Download or clone this repository.
2. Open `project10_file_manager.py`.
3. Run the program.
4. Select the folder you want to organize.
5. The program automatically creates folders and moves files according to their type.

## 💼 Real-World Use

This tool can help users organize large numbers of files automatically instead of manually moving them into different folders.

Built as a practical Python automation project to solve a real-world file-management problem.
