#File Organizer
A Python automation project that organizes files into different folders based on their file type
##Features
-detects file extensions
-create  category folders automatically
-organizes python files
-organizes text files 
-organizes image files
-organize document files
-Move files automatically using Python
##Categories
-python: '.py'
text: '.txt'
Image: '.jpg','.jpeg','.png'
Document: '.pdf','.docx'
##technologies used
-python
-os module
-shutil module
## How to Run
1.open'file_organizer.py'
2.Select the folder you want to organize.
3.Run the program.
4.the program creates category folders automatically.
5.file are moved into their respective folders.
###project Goal
This project was created to practice python file handling , automation,loop,dictionaries and working with the operating system.
